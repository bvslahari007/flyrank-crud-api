# Task API — CRUD Assignment (FlyRank W2 · A1)

A small to-do list API built with **FastAPI** as part of the FlyRank Backend AI Engineering internship (Week 2, Assignment A1). Supports full CRUD (Create, Read, Update, Delete) on an in-memory list of tasks, with interactive docs via Swagger UI.

## What this is

This API manages a simple in-memory to-do list. You can create tasks, list them, fetch one by id, update a task's title and/or completion status, and delete a task — the four CRUD operations, built stage by stage while learning the request/response loop from the server side.

Data is **in-memory only** — it resets every time the server restarts. There's no database yet; that's intentional, and comes in a later assignment.

## How to run it

Requires Python 3.10+.

```bash
git clone <https://github.com/bvslahari007/flyrank-crud-api>
cd first-crud-api
python3 -m venv venv
source venv/bin/activate
pip install fastapi uvicorn
uvicorn main:app --reload
```

The server starts on **http://localhost:8000**.

## Endpoints

| Method | Path              | Description                          |
|--------|-------------------|---------------------------------------|
| GET    | `/`               | Describes the API                    |
| GET    | `/health`         | Health check — confirms the server is alive |
| GET    | `/tasks`          | List all tasks                       |
| POST   | `/tasks`          | Create a new task                    |
| GET    | `/tasks/{task_id}`| Get a single task by id              |
| PUT    | `/tasks/{task_id}`| Update a task's title and/or done status |
| DELETE | `/tasks/{task_id}`| Delete a task                        |

## Example request

```bash
curl -i -X POST http://localhost:8000/tasks -H "Content-Type: application/json" -d '{"title":"Buy milk"}'
```

```
HTTP/1.1 201 Created
content-type: application/json

{"id":4,"title":"Buy milk","done":false}
```

## Notes

- Data lives only in memory — restarting the server resets it to the 3 seed tasks.
- Validation: `POST`/`PUT` requests with a missing `title` return `422` (FastAPI's built-in schema validation); requests with an empty-string `title` return `400` (custom validation in the endpoint).
